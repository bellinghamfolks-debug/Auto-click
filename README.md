# مكفوف كليكر - تطبيق نقرات تلقائية للمكفوفين

تطبيق أندرويد أصلي بلغة Java مخصص للمكفوفين وضعاف البصر. يعمل بالكامل عبر خدمة إمكانية الوصول (Accessibility Service) ولا يحتاج صلاحية الجذر، ولا يتجاوز حماية أي تطبيق - فقط ينفذ نقرات وتمريرات يحددها المستخدم نفسه.

---

## ملخص سريع جدًا

- التطبيق ليس تطبيق ويب، وليس React Native. هو **مشروع Android Studio حقيقي** بلغة Java.
- لا تحتاج تفتح Android Studio أبدًا. الـ APK يُبنى تلقائيًا في **GitHub Actions**.
- كل الواجهة باللغة العربية، أزرار كبيرة، متوافقة مع **TalkBack**.

---

## خطوات الحصول على ملف APK جاهز للتثبيت

### الخطوة 1: ارفع المشروع إلى GitHub
- داخل منصة Emergent، اضغط زر **"Save to GitHub"** في أعلى يمين الشاشة (متوافق مع قارئ الشاشة).
- اختر مستودع جديد أو موجود، وأكّد الرفع.

### الخطوة 2: انتظر بناء الـ APK تلقائيًا (3-5 دقائق)
- بمجرد رفع الكود، ستبدأ GitHub Actions في بناء التطبيق تلقائيًا.
- لمتابعة التقدم: افتح صفحة المستودع على GitHub.com -> تبويب **Actions**.

### الخطوة 3: حمّل ملف APK
- بعد اكتمال البناء (علامة صح خضراء):
  1. اضغط على آخر workflow run.
  2. انزل لقسم **Artifacts** في أسفل الصفحة.
  3. اضغط على `mokafeefah-clicker-apk` ليبدأ التحميل تلقائيًا.
  4. ستحصل على ملف ZIP بداخله `mokafeefah-clicker-debug.apk`.

### الخطوة 4 (اختياري): إصدار رسمي مع APK جاهز
- في صفحة Actions، اختر workflow "Build Android APK" -> زر **Run workflow** -> Run.
- بعد اكتمال البناء، سيتم إنشاء **Release** في صفحة المستودع مع رابط تحميل مباشر للـ APK (بدون الحاجة لفك ZIP).

### الخطوة 5: ثبّت الـ APK على هاتفك
1. انقل ملف APK إلى هاتف الأندرويد.
2. افتح الملف من مدير الملفات. قد يطلب الهاتف منك السماح بـ "تثبيت من مصادر غير معروفة" - وافق.
3. اضغط "تثبيت".

### الخطوة 6: فعّل خدمة إمكانية الوصول
1. افتح التطبيق "مكفوف كليكر".
2. اضغط زر **"فتح إعدادات إمكانية الوصول"**.
3. ابحث عن "خدمة النقر التلقائي للمكفوفين" أو "مكفوف كليكر".
4. فعّلها. سيظهر تحذير من النظام - وافق.
5. ارجع إلى التطبيق. ستظهر حالة الخدمة: **مفعلة**.

## كيفية الاستخدام

1. **حدد الإحداثيات**: لكل تطبيق هدف (مثل مودة)، تحتاج معرفة إحداثيات زر الإعجاب وزر "نعم". يمكنك:
   - تفعيل "Pointer location" من إعدادات المطور في الأندرويد لرؤية الإحداثيات.
   - أو اطلب من شخص مبصر تحديدها لك مرة واحدة.
2. **أدخل القيم** في الحقول العربية.
3. **اضبط مدة الانتظار** (مثلًا 1500 ميلي ثانية = 1.5 ثانية).
4. **اختر عدد التكرار** (كم عضو تريد إرسال إعجاب له).
5. **اختياري**: فعّل خيار "التمرير لأسفل بعد كل عملية".
6. افتح التطبيق الهدف (مثل مودة) وانتقل للصفحة المطلوبة.
7. ارجع لتطبيقنا واضغط **"بدء التشغيل"**.
8. سيقوم التطبيق تلقائيًا بنقر زر الإعجاب، ثم زر نعم، ثم التمرير، وتكرار العملية.
9. لإيقاف التنفيذ في أي وقت: ارجع للتطبيق واضغط **"إيقاف التشغيل"**.

## الميزات

- ✅ مكتوب بـ Java الأصلي - بدون أي إطار عمل ويب
- ✅ يعمل عبر `AccessibilityService` فقط - لا روت، لا تجاوز حماية
- ✅ واجهة عربية بالكامل مع RTL
- ✅ متوافق مع TalkBack: كل زر وحقل له وصف عربي
- ✅ أزرار كبيرة (64dp) بألوان متباينة
- ✅ يحفظ الإعدادات تلقائيًا عند الخروج
- ✅ زر "تجربة نقرة" لاختبار الإحداثيات قبل التشغيل
- ✅ إيقاف فوري عند الضغط على إيقاف
- ✅ يمنع تشغيل أكثر من عملية في نفس الوقت
- ✅ يعرض الحالة الحية: خامل / يعمل / متوقف / مكتمل

## التراخيص والأمان

- لا يطلب التطبيق أي إذن خطير (Camera, Location, Contacts...)
- الإذن الوحيد المستخدم هو `BIND_ACCESSIBILITY_SERVICE` (يُمنح للخدمة فقط من قِبل النظام)
- لا يتصل التطبيق بأي خادم خارجي
- جميع البيانات محفوظة محليًا في `SharedPreferences`
- الكود مفتوح المصدر، يمكنك مراجعة كل سطر منه

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| الخدمة لا تظهر في إعدادات إمكانية الوصول | تأكد من تثبيت APK كاملًا. أعد فتح إعدادات إمكانية الوصول. |
| النقرات لا تعمل | تحقق أن الإحداثيات صحيحة بزر "تجربة نقرة". |
| GitHub Actions يفشل | راجع تبويب Actions، سيظهر سبب الخطأ. عادةً مشكلة في اتصال أو خطأ مؤقت - أعد التشغيل. |
| لا أعرف إحداثيات الأزرار | فعّل "Pointer location" من خيارات المطور، أو اطلب مساعدة. |
